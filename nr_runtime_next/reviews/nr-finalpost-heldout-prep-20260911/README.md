## Source-backed contraction policies

`STATIC_PROOF.json` checks **all 3336 original SASS instruction encodings** against the untouched ELF and retains the no-texture exclusion certificates for all 14 TEX sites.

1. **Separate RN**: `RNhalf(RNhalf(x*x)+RNhalf(y*y))`; merge also rounds both products separately.
2. **QK fused**: local copy of the corrected numeric-gap proof certifies **all 32 Q/K first-square folds**. The second square retains HMUL2 rounding: `RNhalf(x*x + RNhalf(y*y))`. It tracks versioned A inputs, B bases and D-word identities, not opcode counts or old-fixture matches.
3. **Merge + QK fused**: the new merge proof covers **all 32 HFMA2 sites**, **all 32 rounded main HMUL2 addends**, all eight coefficient loads, and all four main/four skip input load chains. Every FMA folds **skip × slab8336** into already-rounded **main × slab8272**, with the same address lineage for the coefficient pair. All 32 distinct skip load-word/half-pairs are covered exactly once.

The merge proof follows input pointer roots (+0 main, +8 skip, +24 slab), guard versions, zero alternatives, widening, shuffles, selects, scalar coefficients and overwritten registers, including overlapping pointer/vector words. A separate forward **PTX CFG type analysis** checks the raw/zero alternatives and operand families at all 32 logical merges. Unknown definitions fail closed. This is a uniform **family/fold-direction proof**, not a newly asserted SASS↔PTX physical tile permutation or a general GPU layout emulator. It uses the existing pinned original-layout CPU reference.

All required fold-direction sites passed, so the third policy is source-backed rather than an unverified candidate. If these proofs/pins fail, the API rejects the case; it never silently substitutes an uncertain merge policy. Any later artifact/source discrepancy must be reported as policy uncertainty, not interpreted as proof of a different fold.

The transformations replace exactly **0 / 32 / 64** certified CPU expressions. They are in-memory interpreter inputs only; no transformed PTX file is emitted or compiled.

## Generic bounded CPU API

`cpu_api.predict(args, main, skip, slab, blend, *, grid, block, policy, approximation, mma)` accepts **arbitrary** finite E4M3 feature bytes within .25 at these exact extents, not just the frozen fixture hashes. A separate nonfixture input containing zero, signed zero and subnormal codes passes a connected smoke check. Nonfinite inputs/unsupported contracts/overflow fail closed.

The strict enums are `Policy`, `Approximation.RN_F32`, and `MMA.EXACT_STAGED_RN`; strings, bools, integer substitutes and unrelated enums reject. `arguments()` produces symbolic CPU memory keys, never actual allocation addresses. `prefix_run` uses local transformed strings with no global interpreter monkeypatch. Prefix reads must match independent source-layout equations; every memory read is bounded. Tail slab readers retain their own bounds checks.

CPU decode is an arithmetic-identical local copy of the old epilogue reference, replacing only `find_library('m')` discovery with literal **CPU `libm.so.6`** to avoid helper subprocesses. The audit guard blocks all subprocesses, CUDA libraries/device opens, external writes and old GPU readbacks. It permits ordinary Python process/CPU-libm loading only. An initial guard rejected Python's process-handle initialization **before any prediction**; `freeze-import-guard.log` retains that setup failure. No numeric algorithm or fixture changed to address it.
