## 结论先行

**新证据比两条早期 ZZZ 测试更有针对性：确有 ZZZ 作者明确写“叠三层 脸不黑”，燕云评论中也有两名观众自述双层效果并附图。** 这不是从 FG3x、插件数量或“三小只”推出来的。但本轮仍没取得能复现指定“通透、写实质感”的完整参数／预设，也没验证实际 NR 执行链。

- **不要求抖音／B站同源**，不把无法匹配来源作为终止理由。
- **不以“只是滤镜／mod”排除效果，也不把观众的“像 AI 视频”审美评论升级为“视频是 AI 生成”判定。** “通透”是待解释的视觉描述，本轮没有量化皮肤透光、SSS 或渲染机理。

## 访问与负证据边界

- 先逐条读了两份原保存评论，连同 metadata 原样复制并记录 SHA256；随后重新请求六个目标的普通 `x/v2/reply?type=1&oid=…&sort=2&pn=1`，全部 HTTP200/code0。

- 请求每个目标的 `sort=0&pn=1`、`sort=2&pn=2`：12 次均 HTTP200/code0，但 `page.num/size/count=0`、`replies=null`、`upper.mid=0`。**这是不可用的空壳响应，不是“评论区为空／没有作者回复”证据。** 没有明确服务端文字说明原因，因此不武断指定是登录限制。
