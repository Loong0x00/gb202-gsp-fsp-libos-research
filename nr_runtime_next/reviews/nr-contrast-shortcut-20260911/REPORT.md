# NR 是否只是「高对比、全部压暗」？CPU 留存像素审计

**结论：这两个样本不支持“全部压暗”这个概括。全局色调变换能拟合相当一部分编辑，但不能完整复现输出；剩余差异也不能直接称为 3D、几何或真实材质恢复。无法据此推断训练意图。**

## 主要数值

以下 Y 均为线性光亮度：B/P 和旧人像先做 inverse-sRGB；S/D 已是 linear HDR。代理域解码后的 EV 不等于原场景辐射曝光。亮度变化为 `log2(mean(Yout)/mean(Yin))`。

| 独立列示的比较 | 平均 Y 变化 | EV | 曝光增益残差比 | 全局 Y 单调曲线残差比 | 三通道全局单调曲线残差比 |
|---|---:|---:|---:|---:|---:|
| WuWa frame2 B→P5，原始代理输出 | +52.0% | +0.604 | 0.708 | 0.716 | 0.597 |
| WuWa frame3 B→P5，原始代理输出 | +63.2% | +0.707 | 0.638 | 0.647 | 0.531 |
| WuWa frame2 S→D，**外部 HDR 合成** | +31.0% | +0.389 | 0.986 | 0.711 | 0.238 |
| WuWa frame3 S→D，**外部 HDR 合成** | +37.7% | +0.461 | 1.031 | 0.709 | 0.243 |
| 旧人像 Style0，input→raw model | −6.4% | −0.095 | 0.774 | 0.375 | 0.314 |

**残差比 = 留出像素 Σ‖预测−目标‖² / Σ‖目标−输入‖²，表内为线性 RGB。** 0 为完全复现编辑，1 相当于不编辑；允许 >1。它不是图像 R²，更不是“解释了多少 3D”。Y 曲线优化亮度而非 RGB，因此其 RGB 分数不保证优于 RGB 最小二乘增益。

- **WuWa 是“总体变亮，同时局部更黑/更亮”，不是全图压暗。** frame3 B→P5 的像素 EV 中位数 +0.669，5–95 分位 −1.190 至 +1.859；23.8% 像素变暗。深暗比例 `Y<0.01` 从约 0.002% 增至 1.52%，`Y<0.05` 从 8.31% 增至 8.90%；全图 log2Y 标准差从 0.919 增至 1.370。平均变亮与阴影加深可以并存。
- 两帧 B→P1…P5 的平均亮度 EV 分别为 **+.122/.253/.381/.500/.604** 与 **+.160/.317/.465/.599/.707**。P1→P5 的三通道曲线仍留下 0.504 / 0.455 的 RGB 编辑残差比。
- **旧人像有压低亮部/改变肤色及皮衣反光的现象，但也抬升最深阴影。** `Y<0.01` 从 27.29% 降至 23.93%，`Y<0.05` 从 33.60% 增至 34.70%；log2Y 标准差反而从 3.610 降至 2.921。全局非线性曲线远比单一曝光贴近该输出，但仍留下约 0.31–0.37 的 RGB 编辑残差比。不能把旧报告的代理码值亮度比与这里的线性光亮度比混用。
- **HDR 的低 RGB 残差比尤其容易误导。** frame3 三通道曲线全图为 0.243，但只看输入 `Y≤1` 是 0.488，log2Y 编辑残差比为 0.653。少量高强度、变色的高光影响全图 RGB 能量很大；这个数字并不说明多数可见区域已复现。

## 方法与核查

- 限定 **一个 WuWa 静态场景的两帧 + 一张旧人像**，18 个原始 RGBA 文件；没有扩展样本扫描。WuWa 原生 768×432、人像原生 1920×1920 统计和拟合；只在拼图显示时缩小。
- 双折棋盘块留出：WuWa 64×64、人像 160×160；每折只使用另一组块训练，然后只预测留出块。不是随机像素拆分。相邻块仍相关，两帧也不是独立场景，故不是跨图泛化结论。
- 模型：共享非负 RGB 最小二乘增益；128 个等计数输入亮度箱的加权 isotonic 单调曲线（保留输入色度）；另加更宽松的三条独立 RGB 单调曲线。曲线线性插值、端点线性外推并限制非负。没有目标导出的逐像素/局部 oracle 特征。
- 32/512 箱敏感性检查：WuWa frame3 原始 B→P5 三通道曲线残差比均约 0.531；人像为 0.328/0.311，结论稳定。HDR **Y 曲线**对稀疏高光和外推敏感，残差比 0.753/1.264，不能当成稳定最佳拟合；三通道 HDR 曲线为 0.249/0.237。固定 128 箱主结果未按测试成绩择优。
- CPU identity / gain0.63 / Y^1.7 / RGB^1.7 单元测试全部通过。身份编辑分母为零时报告 null；精确增益残差约 5e−32；两种非线性对应曲线残差约 5.3e−7 / 4.1e−9。45 组结果的 RMSE 比平方及逐块能量加权均核验通过；30 个来源/脚本 SHA256、12 个 PNG 完整性核验通过。
- 运行：`PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python audit.py`，同样环境运行 `python verify.py`。主审计约 12 秒。只用 CPU/NumPy/SciPy/Pillow，未执行模型、GPU、Wine、游戏或修改运行时设置。

完整分位数、阴影比例、逐折/逐块结果、拟合参数和消融参数见 [metrics.json](metrics.json)；箱数检查见 [verification.json](verification.json)。
